# Artwork provenance

`parker-square.svg` is an original deterministic rendering made for this
repository. It uses the genuine entries of Matt Parker's semi-magic square,
as described on [Brady Haran's Parker Square
page](https://www.bradyharanblog.com/the-parker-square), but does not copy or
embed the image published there.

The arithmetic shown in the SVG is exact:

```text
29^2   1^2  47^2
41^2  37^2   1^2
23^2  41^2  29^2
```

Every row, every column, and the main diagonal sums to `3051`. The other
diagonal sums to `4107`. The entries `1^2`, `29^2`, and `41^2` are repeated,
so the square misses both requirements of the open problem.
